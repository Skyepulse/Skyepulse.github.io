SkyePhyX — Augmented Vertex Block Descent

Real-time constraint-based physics running in-browser via WebGPU.
Implements AVBD (Giles, Diaz, Yuksel — SIGGRAPH 2025) on top of VBD (Chen, Liu, Yang, Yuksel — SIGGRAPH 2024). Rigid bodies, soft bodies (Neo-Hookean / StVK FEM), contacts, collision detection, friction, and joints.

Camera

  • LMB drag — orbit
  • RMB Either pick a dynamic body OR shoot sphere (radio button choose)
  • W / Z — forward
  • S — backward
  • A / Q — strafe left
  • D — strafe right
  • ↑ / ↓ — up / down
  • ← / → — rotate
  • Shift — 6× speed

Simulation

  • P — pause / resume
  • N — single step (while paused)
  • R — restart level
  • B — spawn random rigidBody

UI Panel

  • Use the ImGui overlay to switch levels and tune Young's modulus, Poisson's ratio, and time step in real time.

Built with WebGPU (emdawnwebgpu), Emscripten, Eigen 3.4, and Dear ImGui 1.92.
